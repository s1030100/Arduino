# 100-Mendako 🐙

Arduino UNO R4 WiFi を使用した、超音波センサーとサーボモーターでリアクションする「メンダコ」ロボットのスケッチです。手が近づくと内蔵LEDマトリクスの表情が「にっこり」に変わり、首をかしげる動作をします。

---

## 🔌 回路・配線図 (Wiring)

| デバイス | ピン名 | 接続先 (Arduino UNO R4 WiFi) | 備考 |
| --- | --- | --- | --- |

|  | Trig | **Pin 4** | 距離計測トリガー |
|  | Echo | **Pin 3** | 距離計測エコー |

## 🛠️ 主な仕様・動作 (Features)

1. **通常時**: LEDマトリクスに「パッチリ目 `(-_-)`」を表示し、数秒おきにランダムでまばたきをします。
2. **センサー検知**: 超音波センサーで **15cm 以内** に障害物（手など）を検知します。
3. **リアクション**: 検知するとLEDが「にっこり目 `(*^^*)`」に変化し、サーボモーターが首を傾げます（120度）。
